Otter MCP Server

Otter Help
July 30, 2026 21:04 Updated

Connect AI models to Otter using Model Context Protocol (MCP). Connecting Otter MCP to your AI applications enables secure, scalable access to various language model understandings to power features like smarter summaries, contextual suggestions, and automated insights for all your Otter conversations and meetings.

Learn to connect to Claude, ChatGPT, Curors, Perplexity, or other platforms.

What is Model Context Protocol (MCP)?

MCP is an open standard that allows AI assistants like Claude and ChatGPT
to securely access external data sources. With Otter’s MCP Server, these AI
assistants can:

✅ Search your meeting transcripts across all time periods

✅ Analyze patterns and themes across multiple meetings

✅ Generate content using your actual meeting data

✅ Surface insights without leaving your AI workflow

🔑 Key advantage: Your meeting knowledge becomes instantly accessible to AI
assistants, eliminating manual copy-paste and context-switching.

🔒 Security: All access is OAuth-authenticated with granular permissions.
Your AI assistant can only access meetings you explicitly authorize.

Claude setup Learn how to set up Claude

Check out Otter.ai in the Claude connectors directory.

Connect Otter MCP to Claude.

  1. Go to Settings → Connectors → Browse connectors. 

    Note: If your workspace admin has already added Otter.ai, it will appear as an available connector. Click Connect and proceed directly to Step 3.

  2. Go to Claude's Otter.ai page and click Connect.

  3. Sign in to your Otter account. Review the info and click Authorize access to connect with Claude.

  4. Otter MCP is connected to Claude.

Enable Otter MCP tool with chat

Click on the search and tools menu in the chat box. Toggle on Otter. 

Configure your Otter MCP tool permissions

Claude will prompt for permissions when querying using Otter MCP tools.

You can manage permissions for the Otter MCP tool in the connector settings. 

  1. Under the settings Connectors, click Configure next to Otter or manage through the 3-dot menu.

  2. Manage each of the tools' permissions. We recommend setting it to Always allow.

ChatGPT setup Learn how to set up ChatGPT

Connect Otter MCP to ChatGPT. Otter.ai is available in the ChatGPT App Store. 

Check out Otter.ai in the ChatGPT App Store.

  1. Sign in to the ChatGPT web version. Go to Settings. 

    Note: To connect to Otter MCP, you must currently complete the connection through the web version of Otter. Connecting directly through the desktop app is not yet supported. Once the connection is established on the web, it will automatically be available in the desktop app.

  2. Go to Apps and add apps. The option may vary depending on your existing account.
  3. Go to Otter.ai in the ChatGPT App Store.
  4. Click Connect.
  5. Carefully review the information and click Connect Otter.ai.
  6. Sign in to your Otter.ai account. Carefully review the information and click Authorize access to proceed.
  7. Otter.ai is now connected to your ChatGPT account. 

Enable Otter MCP tools with ChatGPT. Now that Otter is connected, you can work from the ChatGPT web browser or the desktop app. 

  • Click the + (plus icon). Click ••• More and select Otter.ai.
  • Type @ and select Otter.ai. 

When starting a new chat, make sure Otter.ai is showing. If you do not see otter.ai, select it again through the steps above.

Using Otter MCP tools with ChatGPT

Otter uses 3 tools in ChatGPT to query your meetings: 

  • fetch
  • get user info
  • search

If prompted, accept the tool request to proceed. 

You can click any source to go directly to the Otter conversation. 

If you are experiencing any issues querying your Otter conversations, we recommend specifically mentioning the Otter tool you want to use in your query.

Manage Otter MCP settings for ChatGPT in Apps.

Cursor setup Learn how to set up Cursor

Connect Otter MCP to Cursor. Refer to Cursor’s documentation on connecting MCP servers for more info.

  1. Navigate to Cursor settings. Click Tools & MCP. Click Add Custom MCP.

  2. Configure the JSON file with the following. Save changes to the file.

    {
  "mcpServers": {
    "otter_meeting_mcp": {
      "url": "https://mcp.otter.ai/mcp"
    }
  }
}

  3. Navigate back to Tools & MCP. Click Connect.

  4. Click Open.

  5. Sign in to your Otter account. Click Authorize access. 

  6. Otter MCP is connected to Cursor.

Enable Cursor

Enable Otter MCP by ensuring it's toggled ON under Cursor Tools & MCP settings and tools enabled. Cursor will automatically use available tools. 

If a tool is disabled, click on the grayed-out tool to re-enable.

Perplexity Learn how to set up Perplexity

Connect Otter MCP to Perplexity using custom connectors to securely access and reference your Otter conversations, meeting notes, and AI insights directly within Perplexity. 

Note: Perplexity’s UI may change over time. Refer to Perplexity’s documentation for the latest instructions on connecting a custom connector. 
  1. Navigate to the Connectors settings page. The location may vary depending on whether you are using an individual or an Enterprise account. 

  2. Click + Custom connector.

  3. Configure using the following settings and click Add. 
    • Name: Otter.ai
    • Description: Meetings from Otter

    • MCP server URL: https://mcp.otter.ai/mcp

      Icon: The Otter icon can be downloaded here.

  4. Sign in to your Otter account and click Authorize access.

  5. Otter MCP is connected to Perplexity.

Enable Perplexity

Make sure the connector is enabled before submitting your query. You may need to grant permissions the first time you use the provided tools. 

Connect Otter MCP to other AI tools You may be able to connect Otter MCP to your AI tool depending on your platform

Otter MCP can be connected to third-party AI tools that support the Model Context Protocol (MCP) using a JSON configuration file. Setup varies by platform and is managed entirely within your AI tool’s configuration. Configuration, behavior, and support depend on the specific platform you are using. Refer to your tool's documentation to connect to an MCP server.

Before you begin

  • Your AI tool must support MCP
  • You should be familiar with editing JSON configuration files
  • OAuth authentication is still required to connect 

JSON Configuration file

{
  "mcpServers": {
    "otter": {
      "url": "https://mcp.otter.ai/mcp"
    }
  }
}

Complete setup in your AI tool

  1. Add a custom MCP and configure the JSON file with the above. 
  2. Connect and authenticate with your Otter account.
  3. Verify the Otter MCP server appears, and tools are available. 
Note: We’ll continue adding step-by-step guides for more AI tools. In the meantime, setup may vary by platform and is completed at your discretion.

FAQs

Is Otter MCP available for all AI applications? 

  • We are working to release Otter MCP for all AI applications. Contact our Otter Support Team for help setting up Otter MCP with your AI application. 
Note: Google Gemini's support for MCP tools is not yet available, according to this thread; however, Gemini's command line interface (CLI) does support connecting to MCPs. Refer to Google's documentation for the most up-to-date information. 

Is Google Gemini supported?

  • No. 
  • According to this thread, Google Gemini does not yet support MCP tools.
  • However, Gemini's command line interface (CLI) does support connecting to MCPs. 
Note: Refer to Google's documentation for the most up-to-date information.

What meetings can I access through the MCP Server?

  • You can access all meetings that you have captured in Otter, as well as any meetings shared with you from other users in your Workspace. 
  • Learn more about conversation sharing and Channels in Otter.

Can I connect Otter MCP on the ChatGPT desktop app?

  • Connecting Otter MCP on ChatGPT desktop app is not yet available. Connect Otter MCP on the web version of ChatGPT.

Is there a public API key for me to set up Otter MCP for my AI application?

  • We currently do not have a public API key at this time. Contact our Otter Support Team for help setting up Otter MCP with your AI application. 

Where can I download the Otter icon?
